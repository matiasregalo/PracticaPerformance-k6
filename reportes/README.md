# reportes — carpeta generada automáticamente

Esta carpeta es creada manualmente antes de ejecutar el test.
Al finalizar la ejecución, k6 deposita aquí dos archivos:

- `resultado-prueba.html` — reporte visual interactivo (abrir en el navegador)
- `resultado-prueba.json` — datos crudos de todas las métricas

Consultar `readme.txt` para instrucciones de ejecución.
